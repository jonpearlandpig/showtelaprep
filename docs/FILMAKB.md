# FilmAKB

FilmAKB is the Authoritative Knowledge Base for a production.

FilmAKB is not a chatbot memory and not a generic project database. It is the operational truth layer that stores artifacts, registries, lineage, relationships, and history.

## Authority Rules

- Artifacts are authority.
- Derived facts must reference artifacts, decisions, assumptions, or replay events.
- Unknown information returns: "Not found in current FilmAKB."
- All generated intelligence must preserve provenance.

## Stored Domains

- Artifacts
- Scenes
- Characters
- Locations
- Crew
- Cast
- Schedules
- Risks
- Decisions
- Assumptions
- TELAwhy
- Timeline events
- Replay events
- Relationships
