# UI Constitution

ShowTELA Prep should feel 70% Netflix, 20% Apple Photos, and 10% production office.

## Product Feeling

The user is browsing a production.

Avoid spreadsheet, database, enterprise dashboard, and generic project-management patterns.

## Navigation

Desktop:

- Home
- Search
- Production
- Ask TELA
- Messages
- Profile

Mobile:

- Home
- Search
- Ask TELA
- Production
- Profile

## Required Surfaces

- Login with Netflix-style profile selection
- Home
- Production Brief
- Search
- Ask TELA
- TELAwhy
- Location Detail
- Scene Detail
- Morning Brief
- Timeline
- Artifact Library
- Production Replay

## Feedback Law

Within 10 seconds, the user must understand:

- what is happening
- what changed
- what is blocked
- what needs approval
- what happens next
